OpenEmu-Silicon — RetroAchievements Review Build

This disk image contains both the review app and the updated native RetroAchievements core plugins built from the same source checkpoint.

Build Identity

App version: 1.2.6 (release candidate)

Purpose: New system/core additions and rcheevos 12.4.0 library update

Code Changes: PR #687

Source commit: dcf5f98ff

Install

  1. Double-click Install from this disk image.
    This installs the app to /Applications and copies the core plugins to ~/Library/Application Support/OpenEmu/Cores/.
  2. Launch OpenEmu from /Applications.
  3. Open OpenEmu → Settings/Preferences → Achievements, sign into RetroAchievements, and enable Hardcore Mode (if testing hardcore compliance).
